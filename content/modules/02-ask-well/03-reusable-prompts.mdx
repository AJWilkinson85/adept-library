## A prompt that worked once is a recipe waiting to happen

When a prompt produces something you actually used, do not let it disappear into chat history. Save it. The savings from these tools do not come from clever one-off requests; they come from the six or seven recurring tasks you do every week, each with a prompt that gets a little better every month.

## The recipe format

Every saved prompt in this library uses the same shape, so anyone in the office can run it.

```
NAME: Decline-a-job email
WHEN: A customer asks for work we don't do or can't schedule
PASTE FIRST: business brief
ATTACH: nothing
PROMPT:
[the prompt text, with [BRACKETS] for the parts that change each time]
CHECK: prices, dates, anyone's name
```

The CHECK line is the thirty-second check from Module 1, written down for the specific task, so a new person knows what to verify.

## Where to keep them

A shared document, a folder of text files, or your tool's saved-prompts feature if it has one. What matters is that there is exactly one place, and that it is the same place for everyone. A "prompt library" in the office is nothing more than this document with twenty entries in it.

<Callout kind="note">
Name recipes by the situation, not by the tool. "Chase an unpaid invoice" beats "Prompt 4." People search for the problem they have.
</Callout>

## Improving a recipe

When a recipe produces a bad draft, do not fix the draft and move on. Fix the recipe. Usually it is one of three things: a missing constraint ("do not offer a discount"), a missing piece of context ("they are a repeat customer"), or a missing example ("here's how I said it last time"). Add the line, save, and the next person gets the better version.

<Prompt title="Turn a good result into a recipe">
The last draft you wrote worked well. Write me a reusable prompt recipe for this task in this exact format: NAME, WHEN, PASTE FIRST, ATTACH, PROMPT (with [BRACKETS] for the parts that change each time), CHECK (what a person must verify before sending). Keep the PROMPT section under 150 words and make it produce the same tone and structure as the draft you just wrote.
</Prompt>

## Your first six

By the end of this library you will have at least six recipes, one from each module. The next three modules each hand you two or three. Start the document now with the one you built in the last lesson.

<Worksheet title="Start the prompt library">
- Create the shared document or folder. Name it "Prompt library."
- Add the recipe for the message you rewrote in lesson 1, using the format above.
- Have one other person in the office run it on a real message without your help. Note what confused them and fix the recipe, not the person.
- Add a line at the top of the document: "Every recipe ends with a CHECK. Do the check."
</Worksheet>
